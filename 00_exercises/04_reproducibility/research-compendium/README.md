# Reproducible Simulation Study

**Author:** Daša Jalen\
**Date:** 14. 11. 2026

The aim of this project was to make a fully reproducible research compendium, following the simulation study in [Boulesteix et al. (2020)](https://bmjopen.bmj.com/content/10/12/e039921). The directory is self-contained and includes all files necessary to generate the report found in the docs folder. To reproduce it, open the .Rproj file in RStudio and run renv::restore() to install the correct package versions.

## Data

Data was downloaded from <https://github.com/mlarpis/markup/tree/main/documents/week-4/raw_data>.

## Original code

The original code script that was adapted for the purpose of this project can be found at <https://github.com/mlarpis/markup/blob/main/documents/week-4/original_script.R>.
